# Дизайн ролевых историй на Android

GramMarket — интерактивная история для двоих. Каждый игрок управляет своим героем, ИИ ведёт остальных персонажей и рассказчика. Главное в сцене — читаемый текст и узнаваемые персонажи. Используй Sea Soul как справку по механикам совместной игры и редактирования, а обложки, портреты, типографику и композицию разработай для GramMarket.

1. Изучи текущие экраны, навигацию, тему и модели состояния. Для каждого изменения установи, какие данные нужны пользователю, какое действие главное и что он увидит во время загрузки, ошибки и восстановления.
2. Прочитай [дизайн-систему](references/design-system.md). Применяй токены через `MaterialTheme`, переиспользуй компоненты и передавай им состояние и обработчики событий. Храни состояние формы и сцены у владельца экрана. Используй стабильные ключи элементов списка для длинной истории.
3. На компактной ширине показывай одну основную область. На широкой сохраняй читаемую ширину текста и используй боковую область для списка историй или карточки персонажа, если она помогает текущей задаче. Проверяй компоновку по ширине окна, включая изменение размера и поворот.
4. Проверь контраст, размеры целей касания, TalkBack, масштаб шрифта и IME. Для сложных системных отступов сверяйся с [edge-to-edge](../edge-to-edge/SKILL.md), для многооконной компоновки — с [adaptive](../adaptive/SKILL.md) с учётом его предусловий и зависимостей проекта.
5. Пройди [визуальную приёмку](references/ui-review.md) через [android-emulator-qa](../android-emulator-qa/SKILL.md). Сравни снятые экраны, устрани проблемы и пересними затронутые состояния. Если APK или эмулятор недоступен, зафиксируй конкретное препятствие и оставшиеся сценарии.

Для визуального направления сверяйся с [Frontend Design](https://github.com/anthropics/claude-plugins-official/tree/main/plugins/frontend-design). Решения для Android проверяй по [Mobile UI](https://developer.android.com/design/ui/mobile) и [Compose Accessibility](https://developer.android.com/codelabs/jetpack-compose-accessibility).
